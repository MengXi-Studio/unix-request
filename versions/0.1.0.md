## 一、为什么做这个库

直接用 `uni.request` 写业务，三件事反复发生：

- **重复封装**：URL 与 query 拼接、header 合并、超时与取消、失败形态归一——每个项目封装一遍，换个项目再来一遍
- **多端差异**：编码行为、失败返回在各端存在差异，逐端排查成本高
- **类型缺位**：`uni.request` 泛回调风格，错误码散落字符串，业务侧只能 `as any`

unix-request 把这些收敛成一套库：写过 axios 的开发者看一眼 API 就能上手；多端发布由库内确定性实现抹平差异；全链路强类型标注。

## 二、核心能力

### 请求主入口 + 七种快捷方法

```uts
import { request, get, post } from '@/uni_modules/mx-request'

// 泛型静态标注 res.data 类型
request<UTSJSONObject>({ url: '/api/http/method/get', method: 'GET' })

// 快捷方法：method 由方法名固定注入（delete 为 UTS 保留字，命名 del）
get<UTSJSONObject>('/users', { params: { page: 1 } as UTSJSONObject })
post<UTSJSONObject>('/login', { user: 'demo' } as UTSJSONObject, null)
```

默认实例开箱即用，`configureRequest` 配置全局默认；`createRequest(defaults)` 创建隔离实例（defaults 与拦截器注册表互不影响），心智对标 `axios.create`。

### 拦截器

请求 / 响应拦截器多枚有序注册、可 `ejectInterceptor(id)` 移除；响应错误链支持三条路径——**恢复**（返回响应）/ **换错**（返回新错误）/ **放行**（返回 `null`），语义对标 axios。

### 统一可预测的错误结构

`RequestError` 收敛 8 类错误码（`ERR_PARAM` / `ERR_CONFIG` / `ERR_CANCELED` / `ERR_TIMEOUT` / `ERR_NETWORK` / `ERR_BAD_REQUEST` / `ERR_BAD_RESPONSE` / `ERR_NATIVE`），原生 `errCode` 经 `nativeErrCode`
原值透传不翻译，`config` 与 `response` 原文挂载——4xx/5xx 响应体不丢失。

### 确定性 URL 与参数处理

`baseURL` 自动拼接（http(s) 开头原样使用）、`params` 与 url 既有 query 合并后由库内统一编码（`encodeURIComponent` + JSON 序列化兜底）、GET/HEAD 的 `UTSJSONObject`
请求体自动并入 query、header 三级浅合并（内置默认 → 实例默认 → 请求级）。

### 请求取消

```uts
import { createCancelSource } from '@/uni_modules/mx-request'

const source = createCancelSource()
request<UTSJSONObject>({ url: '/heavy', cancelToken: source.token })
// 离开页面时：
source.cancel('page unloaded') // 确定性 abort，请求以 ERR_CANCELED reject
```

### 逃生舱

`onTask` 透出原生 `RequestTask`（chunked 分块监听等高级场景）；`enableQuic` / `sslVerify` / `withCredentials` / `enableChunked` 等原生能力参数全量透传不抹平。

## 四、快速上手

```bash
pnpm add @meng-xi/unix-request
mkdir -p uni_modules && cp -R node_modules/@meng-xi/unix-request uni_modules/mx-request
```

```uts
import { request, configureRequest } from '@/uni_modules/mx-request'
import type { RequestError } from '@/uni_modules/mx-request'

configureRequest({
	baseURL: 'https://your.api',
	timeout: 10000,
	header: null,
	validateStatus: null // null 表示沿用内置默认（2xx）
})

request<UTSJSONObject>({ url: '/api/http/method/get' }).then((res) => {
	console.log('statusCode=' + res.statusCode.toString())
}).catch((err) => {
	const e = err as RequestError
	console.log(e.code, e.errMsg)
})
```
